# Masion Nozimi Admin — панель на базе TailAdmin Next.js

Панель управления магазином **Masion Nozimi** (LakLak Market + Instagram).

Форк бесплатного шаблона [TailAdmin/free-nextjs-admin-dashboard](https://github.com/TailAdmin/free-nextjs-admin-dashboard) (MIT).

## Что настроено под магазин

- Dashboard: KPI, графики продаж (план окт–дек), каталог
- Товары — 8 стартовых позиций
- Заказы — журнал LakLak / Instagram
- Финансы — план/факт, капитал 500 TJS, комиссия 0%
- Закупки — первая партия Pinduoduo

## Запуск

Нужен Node.js 20+.

```bash
git clone https://github.com/khurshednozimi/free-nextjs-admin-dashboard.git
cd free-nextjs-admin-dashboard
npm install --legacy-peer-deps
npm run dev
```

Откройте http://localhost:3000
